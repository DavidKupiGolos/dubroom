# DUBROOM: продолжение проекта на другом компьютере

## Назначение

DUBROOM принимает ссылку на публичное YouTube-видео, подготавливает материал на
сервере, показывает реплики по таймингам, записывает пользовательские дубли и
собирает итоговый MP4. Пользовательские архивы не используются.

Публичная версия: https://dubroom.186-246-46-242.sslip.io/

## Запуск

1. Установить Node.js 22.13 или новее, FFmpeg, FFprobe и yt-dlp.
2. Выполнить `npm install`.
3. Создать локальный `.env` по примеру `.env.example`.
4. Запустить `npm run server:v2`.
5. В отдельном терминале запустить `npm run dev`.
6. Открыть `http://127.0.0.1:3000/`.

Файл `.env`, YouTube cookies и данные проектов не должны попадать в Git или
переносимый пакет. Секреты на сервере находятся в `/etc/dubroom/dubroom.env`,
проекты — в `/var/lib/dubroom/projects`.

## Контрольный сценарий

1. Вставить ссылку на собственное публичное YouTube-видео.
2. Дождаться стадии «Готов к озвучке».
3. Проверить оригинальный фрагмент, запись, перезапись и прослушивание дубля.
4. Записать все фрагменты и собрать MP4.
5. Проверить предпросмотр и скачивание результата.
6. В админ-панели проверить текущую стадию проекта и его удаление.

## Важные файлы

- `app/page.tsx` — интерфейс записи и работа с серверным проектом;
- `app/admin/page.tsx` — список и удаление серверных проектов;
- `server-v2/` — загрузка YouTube, ElevenLabs, хранение дублей и сборка MP4;
- `app/globals.css` — визуальный стиль;
- `deploy/` — unit-файлы и установка на Linux-сервер;
- `docs/architecture-v2.md` — архитектурные решения и ограничения.
