# DUBROOM

Браузерная студия озвучки публичных YouTube-видео. Сервер загружает видео,
извлекает звук, получает разделённые дорожки и субтитры через ElevenLabs,
принимает пользовательские дубли и собирает итоговый MP4.

Пользовательские RAR/ZIP-архивы и локальный каталог сцен не поддерживаются.

## Локальный запуск

1. Скопировать `.env.example` в `.env` и заполнить секреты.
2. Установить Node.js 22.13 или новее, FFmpeg, FFprobe и yt-dlp.
3. Выполнить `npm install`.
4. Запустить API: `npm run server:v2`.
5. В другом терминале запустить интерфейс: `npm run dev`.

API по умолчанию работает на `http://127.0.0.1:5180`, интерфейс — на
`http://127.0.0.1:3000`.

## Основной процесс

1. Пользователь вставляет ссылку на собственное публичное YouTube-видео и
   подтверждает права на его использование.
2. Сервер загружает исходник, готовит MP4 и извлекает аудиодорожку.
3. ElevenLabs одновременно разделяет голос и фон и создаёт субтитры с таймингами.
4. Пользователь записывает каждый фрагмент; дубль сразу сохраняется на сервере.
5. После записи всех фрагментов сервер заменяет голосовую дорожку и отдаёт MP4.

Повторная ссылка на то же YouTube-видео в течение 72 часов создаёт отдельную
пользовательскую сессию, но использует уже подготовленные видео, дорожки,
субтитры и тайминги без повторных запросов к YouTube и ElevenLabs.

Админ-панель показывает проекты из серверного хранилища, их стадии и прогресс,
состояние очереди и API, позволяет повторить упавшую задачу или удалить проект,
управлять подготовленным кешем, сроками хранения, допустимыми размерами,
объёмом диска, частотой создания проектов и параллельностью обработки.

Пользовательский проект хранится один час после последней активности. Общий
кэш подготовленных источников отделён от проектов и по умолчанию хранится 72
часа. Оба срока можно изменить в админ-панели.

Незавершённая подготовка и финальная сборка восстанавливаются после перезапуска
API. Активная пользовательская сессия хранится в браузере до истечения срока
проекта и восстанавливается после перезагрузки страницы или повторного открытия
сайта на том же устройстве.

## Команды

- `npm run dev` — локальный интерфейс;
- `npm run server:v2` — локальный API обработки видео;
- `npm run build` — производственная сборка;
- `npm test` — сборка и полный набор автоматических тестов;
- `npm run lint` — проверка исходного кода.
